## 2. 먼저 확인할 것 (사용 전 필수)

1. **MIDI-LLM 라이선스 상충.** LICENSE.md 원문은 Llama 3.2 Community License입니다. 이 라이선스는 'Built with Llama' 표기, 고지 파일 유지, 이용 정책 준수를 요구합니다. README 의 'MIT' 문구와 맞지 않습니다. 법무가 확인해야 합니다. 가중치(`slseanwu/MIDI-LLM_Llama-3.2-1B`)의 라이선스는 열람하지 않았습니다.
2. **MidiCaps·Text2midi·GM 악기표 라이선스 미확인.** 원문에 라이선스 문구가 없거나 열람하지 못했습니다. 확인 전에는 예시 용도로만 쓰고 재배포하지 않습니다.
3. **MAESTRO는 NC 조건.** 비상업 프로젝트 안에서 평가에만 쓰고, 프로젝트에 번들하거나 파생물을 공개하지 않습니다. 공개 시 동일조건(SA) 의무가 붙는지 법무 확인이 필요합니다.
4. **개별 곡 권리.** LMD 와 MidiCaps 의 개별 MIDI 곡 저작권은 원문상 귀속을 확인할 수 없습니다(LMD 원문: Copyright 메타이벤트가 일관되지 않음). 데이터셋 라이선스와 곡 권리는 별개로 봅니다.
5. **POP909 LICENSE 본문** 을 열어 MIT 표기를 확인해야 합니다.

## 3. 열람 범위 (정직하게)

- MidiCaps: 본문 96,495자 중 앞 12,000자만 읽었습니다. 샘플 행은 열람했고 전체 파일은 열지 않았습니다.
- GM 악기표: 위키 본문 20,156자 중 앞 12,000자만 읽었습니다. 프로그램 번호와 드럼 키맵은 확인했고 컨트롤러 부분은 읽지 않았습니다. 위키는 2차 출처이므로 MMA 원문과 교차 확인이 필요합니다.
- Text2midi: 데모 페이지만 열었습니다. 모델·코드 페이지는 열지 않았습니다.
- POP909: 저장소 페이지 일부만 열었습니다. 곡 수는 원문에 없어 '미확인'입니다.
- 항목 8(음계·음역 자료)은 아직 검색하지 않았습니다. 항목 9(music21)는 검색 1회 후 LICENSE 페이지 요약만 열었고, 코드와 corpus 는 열지 않았습니다. corpus 는 별도 라이선스가 있을 수 있어 쓰지 않습니다.
