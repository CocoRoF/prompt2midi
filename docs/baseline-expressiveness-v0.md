## 2. 지표가 대리하는 것과 한계

| 지표 | 대리하는 속성(듣는 사람이 말하는 것) | 이 값이 말해 주지 않는 것 |
|---|---|---|
| 선율 반복률 | 모티프가 돌아오는 정도(“귀에 남는가”) | 반복 위치가 음악적인지. 한 음만 반복해도 1.0 |
| 변주 정도 | 같은 리듬이 반복될 때 음높이가 바뀌는 정도 | 리듬이 달라진 변주는 보지 못함. 장식음과 전혀 다른 선율을 구별하지 못함 |
| 순차/도약 비율 | 선율선의 부드러움·각진 정도 | 음계·조에 따른 음정 의미, 프레이징 |
| 윤곽 다양성 | 마디마다 다른 선율 모양을 쓰는가 | 마디 경계는 악구 경계가 아님. 무작위도 다양함 |
| 종지음=으뜸음 | 선율이 “집”에서 끝나는가(종지감) | 화성과 음 길이. 열린 끝맺음이 의도일 수 있음 |
| 섹션 간 밀도·음역 차 | 섹션별 편곡의 대비(고조되는가) | 세기·음색. 섹션은 사양의 구분이지 들리는 구분이 아님 |
| 코드 간 이동 거리 | 화음 연결의 부드러움(성부 진행) | 좋은 진행인지. 정적인 패드도 부드러움 |
| 음계 이탈률 | 조성 안정 | 경과음·차용화음의 표현적 쓰임을 벌점으로 셈. 음계 안에서만 쓰는 생성기는 자명하게 0 |

**값이 좋아도 음악이 좋다고 말할 수 없는 이유**
1. 모든 지표는 하나의 속성을 *대리*할 뿐이다. 사람이 “표현력 있다”고 느끼는 것은 타이밍·강약·음색·맥락의 합인데 이 지표들은 음표의 위치와 높이만 본다.
2. 지표는 서로 속일 수 있다. 한 음 반복은 반복률 1.0·이탈률 0, 무작위 음열은 윤곽 다양성이 높다. 수치를 맞추는 것과 음악을 만드는 것은 다르다.
3. 방향이 정해져 있지 않다. 반복률이 높은 곡이 *단조로운* 곡일 수도 *중독성 있는* 곡일 수도 있어, 합격선을 두지 않았다(값 열만 기록).
4. 표본이 16곡이고 한 생성기(규칙 공급자)의 같은 구조에서 나왔다. 평균은 이 생성기의 특징일 뿐 음악 일반의 기준이 아니다.
5. 청취 평가(연구 1팀 루브릭)를 대체하지 않는다. 이 지표의 개선을 음악의 개선으로 보고하지 않는다.

## 3. 기준선에서 읽히는 것 (구조에 대한 관찰, 질의 평가 아님)
- **종지음이 으뜸음인 곡: 16곡 중 0곡.** 모든 샘플의 마지막 선율음이 조의 으뜸음이 아니다(예: `s07`은 A단조인데 마지막 음이 C). 규칙 공급자의 모티프 끝 음이 으뜸음이 아닌 구조에서 비롯된 것으로 *보이나*, 원인은 이 PR 에서 확인하지 않았다(코드 분석은 하지 않음). 의도된 열린 끝맺음인지는 청취 평가의 몫이다.
- **선율 반복률 평균 0.7539**: 짧은 모티프를 되풀이하는 구조라서 높게 나온다. 변주 정도 평균 0.6206는 같은 리듬 마디에서 음높이가 꽤 바뀐다는 뜻이지만 얼마나 음악적인지는 알 수 없다.
- **윤곽 다양성 평균 0.0699**: 대부분의 곡에서 마디 윤곽이 한두 가지로 쏠려 있다. `r08` 은 3음 이상인 마디가 2개 미만이라 측정되지 않았다(1곡).
- **섹션 간 밀도 차 0 인 곡 8곡**(`r02`, `r03`, `r04`, `r05`, `r07`, `r09`, `r10`, `s08`): 섹션 에너지가 달라도 음표 수는 같다. 코드 트랙의 연주 방식이 바뀌는 곡에서만 차이가 나는 것으로 *보이며*(추정), 에너지는 음 개수가 아니라 세기(벨로시티) 쪽에 주로 반영될 수 있다. 세기는 이 지표에 들어 있지 않다.
- **코드 간 이동 거리를 측정하지 못한 곡 3곡**(`r03`, `r04`, `r09`): 코드·패드 트랙이 없는 편성(멜로디·베이스·드럼)이다.
- **음계 이탈률**은 거의 0이다. 생성기가 조의 음계 안에서만 쓰기 때문이며(`e09` 블루스만 0.13, 장르 라벨이 없어 완화 한도는 적용되지 않음) 표현의 풍부함을 뜻하지 않는다.

## 4. 한계와 확인하지 못한 것
- 연구 1팀의 정의 문서를 받지 못해 정의는 보수적인 첫 버전이다. 문서가 오면 임계값이 아니라 *정의*를 맞추고 값 열 이름(`expr_*`)은 유지한다.
- 멜로디=채널 0, 코드=채널 2(없으면 3)라는 이 컴파일러의 규칙을 가정한다. 다른 생성기의 MIDI(예: text2midi)에는 그대로 적용되지 않을 수 있다(해당 지표는 `—`).
- 어느 곡도 듣지 않았다. 청취 평가 결과와의 상관은 없다.
- 지표 개수·정의는 앞으로 바뀔 수 있다. 바뀌면 이 기준선(`baseline-v0`)은 그대로 두고 새 기준선(`v1`)을 만든다.
