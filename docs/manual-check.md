# 브라우저 수동 점검 (약 1분)

자동 점검(가짜 DOM + 실제 서버 응답)은 **레이아웃·모바일 폭·포커스 이동·색 대비**를 보지 못한다. 아래를 브라우저에서 한 번 눈으로 확인한다. 서버: `uvicorn prompt2midi.api.app:app --port 8770` (README 참고), 첫 실행 로그의 설정 토큰으로 `/admin` 최초 설정.

| # | 어디서 | 하는 일 | 정상이면 |
|---|---|---|---|
| 1 | `/` (데스크톱 폭) | 페이지를 연다 | 제목·프롬프트 칸·공급자·생성 버튼이 한 열로 가지런하고, 공급자 목록에 "Rule (offline)" 가 보인다 |
| 2 | `/` | 프롬프트에 "밝고 느린 피아노 멜로디" 입력 → 생성 | 결과 카드가 나타나고 사용한 공급자·시드, "MIDI 내려받기" 버튼이 보인다. 키보드 포커스가 결과 카드로 옮겨진다 |
| 3 | `/` | "MIDI 내려받기" 클릭 | `.mid` 파일이 내려받아진다(재생 프로그램에서 열린다) |
| 4 | `/` | "사양(JSON) 보기" 펼치기·접기 | 처음엔 접혀 있고, 펼치면 JSON 이 가로 스크롤 가능한 상자에 보인다 |
| 5 | `/` | 프롬프트 칸을 비운 채 생성 | 빨간 테두리 오류 문구가 보인다(글자 색 대비 충분) |
| 6 | `/` | Tab 키로 처음부터 끝까지 이동 | 건너뛰기 링크 → 프롬프트 → 공급자 → 시드 → 체크박스 → 생성 순, 포커스 표시(주황 윤곽)가 항상 보인다 |
| 7 | `/` (창 폭 360px 이하, 또는 개발자 도구 모바일 모드) | 생성까지 해 본다 | 가로 스크롤이 생기지 않고 버튼이 전체 폭이며 글자가 잘리지 않는다 |
| 8 | `/admin` | 로그인 후 패널 | 상단에 노란 "API 키가 암호화되지 않고 저장됩니다" 배너(P2M_SECRET_KEY 없을 때), 공급자 카드 2개, 제한값·공개 설정 카드가 겹침 없이 보인다 |
| 9 | `/admin` | 키 칸에 가짜 키 입력 → 저장 | 입력칸이 비워지고 "키 등록됨 …끝4자" 만 보인다. 새로 고침해도 키 전체는 어디에도 보이지 않는다 |
| 10 | `/admin` | "연결 테스트" 클릭 | 비용 안내 확인 창이 뜨고, 확인하면 "실패/성공 (ms)" 한 줄이 카드 안에 나온다(가짜 키면 인증 실패) |
| 11 | `/admin` (360px 폭) | 패널 훑기 | 가로 스크롤 없음, 입력칸과 버튼이 잘리지 않음 |

실패한 항목이 있으면 번호와 브라우저 이름·버전, 화면 폭을 적어 알려 주세요.
