최초 설정

서버를 처음 실행하면 콘솔(서버 로그)에 설정 토큰이 한 번 출력됩니다. 토큰과 새 비밀번호를 입력하세요. 토큰은 한 번만 쓸 수 있습니다.

비밀번호를 잃어버리면 복구 링크가 없습니다. 서버의 admin.json 을 지우고 다시 설정해야 합니다.

로그인

API 키가 암호화되지 않고 저장됩니다. 서버에 P2M_SECRET_KEY 환경변수가 없어 키가 평문 파일(secrets.json, 권한 0600)에 들어갑니다. 서버 디스크에 접근할 수 있는 사람은 키를 읽을 수 있습니다.
